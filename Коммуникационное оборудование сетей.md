Сетевой адаптер (Network Interface Card, NIC) — это аппаратное устройство, которое позволяет компьютеру подключаться к сети и обмениваться данными.

Другие названия: сетевая карта, Ethernet-адаптер, LAN-адаптер.

**Основные задачи адаптера**
Преобразование данных — из параллельного формата ПК в последовательный для передачи по сети
Формирование кадров — добавление MAC-адресов, контрольных сумм
Управление доступом к среде — реализация протоколов CSMA/CD (Ethernet), CSMA/CA (Wi-Fi)
Буферизация данных — временное хранение кадров при приёме/передаче

**Функции сетевого адаптера**
**Физическая адресация**
Каждый адаптер имеет уникальный MAC-адрес (48 бит), прошитый производителем. Используется для идентификации устройства в локальной сети.

**Передача/приём данных**
Преобразует биты в электрические/оптические сигналы (передача) и обратно (приём). Контролирует целостность с помощью CRC.

**Управление потоком**
Регулирует скорость передачи для предотвращения переполнения буфера получателя (Flow Control).

**Характеристики сетевых адаптеров**
**Скорость передачи**
10 Мбит/с — Ethernet (устаревший)
100 Мбит/с — Fast Ethernet
1 Гбит/с — Gigabit Ethernet (стандарт)
10 Гбит/с, 25/40/100 Гбит/с — для серверов и ЦОД

**Другие параметры**
Тип интерфейса — PCI, PCIe, USB, M.2
Дуплекс — полудуплекс / полный дуплекс
Поддержка Wake-on-LAN (WoL) — удалённое включение ПК
Поддержка VLAN, QoS — для корпоративных сетей

**Классификация по типу подключения**
**Проводные адаптеры**
Ethernet (RJ-45) — стандартный разъём витой пары
Fiber (SFP/SFP+) — для оптоволоконных сетей

Преимущества — стабильность, высокая скорость, низкая задержка
Недостатки — зависимость от кабеля, ограниченная мобильность

**Беспроводные адаптеры**
Wi-Fi (802.11 a/b/g/n/ac/ax) — беспроводная ЛВС
Bluetooth — короткие расстояния (до 100 м)

Преимущества — мобильность, простота развёртывания
Недостатки — помехи, ниже скорость, безопасность

**Классификация по форм-фактору**
**Встроенные (onboard)**
Интегрированы в материнскую плату. Удобны для обычных ПК и ноутбуков.

**PCI / PCIe карты**
Устанавливаются в слот расширения. Используются для апгрейда или серверов.

**USB-адаптеры**
Подключаются через USB. Портативны, подходят для Wi-Fi, но медленнее PCIe.

**M.2 / NGFF**
Компактный формат для ноутбуков и мини-ПК. Поддерживает Wi-Fi + Bluetooth.

**Драйверы сетевых адаптеров**
Драйвер — программное обеспечение, которое позволяет операционной системе взаимодействовать с сетевым адаптером.

**Основные задачи драйвера**
Инициализация адаптера — настройка при загрузке ОС
Управление передачей/приёмом — формирование кадров, контроль ошибок
Обработка прерываний — уведомление ОС о событиях (приём кадра, ошибка)
Настройка параметров — скорость, дуплекс, MAC-адрес, Wake-on-LAN
